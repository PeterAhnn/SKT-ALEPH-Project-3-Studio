# 짤·카드 스튜디오

SKT ALEPH 과제 3. 사진과 한글 문구로 밈·카드·SNS 이미지를 만드는 정적 웹 편집기.

## 실행

Node.js 22 이상에서 `npm start` 후 http://127.0.0.1:8003 접속. 외부 패키지 설치와 API 키가 필요 없다. 정적 호스팅 디렉터리는 `public`이다.

## 기능

- PNG·JPEG를 실제 파일 헤더와 디코딩 결과로 검증. 12MB / 2,400만 화소 / 한 변 16,000px 제한.
- 업로드 이미지를 긴 변 최대 1,600px로 다시 그려 원본 메타데이터 제거. 원본 파일은 변경하지 않는다.
- 한글 문구·위치·크기·색·정렬·글꼴·테두리, 사진 채우기/전체 보기·어둡기.
- 1:1(1080×1080), 4:5(1080×1350), 9:16(1080×1920). 미리보기 캔버스 자체를 PNG/JPEG로 내려받기.
- 복합 이모지를 보존하는 줄바꿈, 긴 문구 자동 축소. 위 문구 160자, 아래 문구 240자(브라우저 UTF-16 길이 기준).
- 최대 12개 사용자 템플릿 CRUD와 localStorage 보관. 저장 공간 부족 시 실패를 알리고 기존 템플릿 보존.
- 현재 작업과 모든 템플릿을 JSON 백업/복원. 전체 검증과 이미지 디코딩 후 교체 확인을 받고 저장. 외부 URL·SVG는 복원하지 않는다.

## 검사

`npm test`: 데이터 검증과 복합 이모지 회귀 검사 18건.

브라우저 검사는 gstack `/browse`에서 로컬 편집기를 연 후 `eval tests/browser.js`로 실행한다. 이 검사는 해당 테스트 브라우저의 템플릿을 변경하므로 깨끗한 전용 브라우저에서만 실행한다. 다운로드 Blob과 대화상자 응답을 검사 중 가로채며 다운로드 이미지 전체 픽셀을 대조한다. 실제 파일 저장과 시각 검사는 별도로 수행한다.

검사 기록은 `docs/QA.md`, 상세 기준은 `docs/ASSIGNMENT.md`, 제출 문안은 `docs/SUBMISSION.md`를 따른다. `qa`의 원본 증거는 로컬 보관하며 사이트에 배포하지 않는다.

## 안전과 한계

외부 이미지·폰트·분석 SDK·API 요청 없음. 이미지와 문구는 사용 중인 브라우저에만 저장된다. 같은 주소의 브라우저 데이터를 지우거나 시크릿 세션을 종료하면 사라질 수 있으므로 JSON 백업을 권장한다. 다른 탭 동시 편집은 마지막 저장을 기준으로 한다. OS별 기본 글꼴 차이로 다른 기기에서 JSON 복원 시 글꼴 외형은 달라질 수 있다. 같은 화면에서의 미리보기와 파일은 동일한 렌더러를 사용한다.

사용자가 제공하는 이미지의 사용 권한은 사용자에게 있다. 기본 도형 배경은 이 프로젝트에서 직접 작성한 Canvas 코드로 생성하며 외부 사진을 포함하지 않는다. 완성 이미지 3개의 제작 근거는 `docs/ASSETS.md`에 기록한다.
