# 짤·카드 스튜디오

SKT ALEPH 과제 3. 사진과 한글 문구로 밈·카드·SNS 이미지를 만드는 정적 웹 편집기.

## 실행

공개 편집기: https://skt-aleph-project-3-studio.vercel.app

Node.js 22 이상에서 `npm start` 후 http://127.0.0.1:8003 접속. 외부 패키지 설치와 API 키가 필요 없다. 원본은 `public`이며 `npm run build`로 앱 파일과 폰트·라이선스를 `dist`에 복사해 Vercel에 배포한다.

## 기능

- 화면 테마: 시스템(기본)·라이트·다크. 시스템 변경 실시간 반영, 수동 선택 보관. 카드 이미지에는 영향을 주지 않는다.
- PNG·JPEG를 실제 파일 헤더와 디코딩 결과로 검증. 12MB / 2,400만 화소 / 한 변 16,000px 제한.
- 업로드 이미지를 긴 변 최대 1,920px의 무손실 PNG로 다시 그려 원본 메타데이터 제거. 원본 파일은 변경하지 않는다.
- 한글 문구·위치·크기·색·정렬·글꼴·테두리, 사진 채우기/전체 보기·어둡기.
- 무료 한글 폰트 7종(프리텐다드·나눔고딕·나눔명조·검은고딕·주아체·도현체·나눔손글씨 펜)과 기기 기본 글꼴 3종. 선택한 폰트만 같은 서버에서 불러오고 준비 후 저장한다. 출처·OFL 사용 조건은 `docs/FONTS.md`.
- 1:1(1080×1080), 4:5(1080×1350), 9:16(1080×1920). 미리보기 캔버스 자체를 PNG/JPEG로 내려받기.
- 복합 이모지를 보존하는 줄바꿈, 긴 문구 자동 축소. 위 문구 160자, 아래 문구 240자(브라우저 UTF-16 길이 기준). 실제 저장 글자 크기를 표시하고 24px 미만이면 입력 옆과 미리보기에 가독성 경고를 표시한다. 문구를 자동 삭제하지 않는다.
- 최대 12개 사용자 템플릿 CRUD와 IndexedDB 보관. 사진은 별도 자산으로 중복 제거하고 문서와 함께 원자적으로 저장한다. 저장 중/완료/실패를 표시하며 실패 시 기존 저장 자료를 보존한다.
- 내 템플릿 영역의 「백업·가져오기」에서 현재 작업과 모든 템플릿을 JSON 백업/복원. 파일 전체 검증 후 파일명·템플릿 이름과 개수·문구·화면비를 먼저 보여주고 「이 내용으로 복원」을 눌러야 전체 교체한다. 취소·파일 오류·저장 실패 시 기존 작업을 유지한다. 외부 URL·SVG는 복원하지 않는다.

- 모바일 첫 화면에 사진·위/아래 문구 입력을 배치하고 글꼴·배치는 접을 수 있는 상세 설정으로 제공한다.
- 이전 localStorage 작업은 처음 열 때 자동 이전하며 이전 원본은 그대로 남긴다. 손상 자료는 자동 덮어쓰기를 막고 「손상 원본 다운로드」를 제공한다. 새 JSON v2는 사진을 한 번만 포함하며 v1 가져오기도 지원한다.

## 검사

`npm test`: 데이터 검증·복합 이모지 회귀·시스템 테마·폰트·백업 구조 검사 33건. `tests/fonts-browser.js`는 7종의 실제 로드·세 비율 PNG 픽셀 일치·JPEG 디코딩·복원·실패 보존 41건을 검사한다.

브라우저 검사는 gstack `/browse`에서 로컬 편집기를 연 후 `eval tests/browser.js`로 실행한다. 이 검사는 해당 테스트 브라우저의 템플릿을 변경하므로 깨끗한 전용 브라우저에서만 실행한다. 다운로드 Blob과 대화상자 응답을 검사 중 가로채며 다운로드 이미지 전체 픽셀을 대조한다. 실제 파일 저장과 시각 검사는 별도로 수행한다.

검사 기록은 `docs/QA.md`, 상세 기준은 `docs/ASSIGNMENT.md`, 제출 문안은 `docs/SUBMISSION.md`를 따른다. `qa`의 원본 증거는 로컬 보관하며 사이트에 배포하지 않는다.

`tests/backup-browser.js`는 내용 확인 전 무변경, 취소, 손상·필수 누락 거부, 저장 공간 부족 시 보존, 명시적 복원 등 12건을 검사한다. 기존 브라우저 검사와 마찬가지로 테스트 전용 브라우저에서만 실행한다.

큰 사진 CRUD와 반복 복원의 픽셀 보존은 `tests/storage-browser.js`, 실제 재접속 이전과 손상 원본 복구는 `tests/migration-*-browser.js`·`tests/recovery-*-browser.js`·`tests/legacy-recovery-*-browser.js`, 이미지 경계는 `tests/image-boundary-browser.js`로 확인한다. seed 파일은 전용 QA 출처에서만 사용하며 실행 순서는 `docs/STORAGE.md`를 따른다.

## 안전과 한계

2026-09-21 사용자 요청으로 Vercel로 배포를 이전했다. 이전 Sites 주소의 템플릿은 자동 이전되지 않으므로 옛 주소에서 JSON 백업 후 새 Vercel 주소에서 복원한다. 배포·테마 검사와 매뉴얼 확인은 docs/DEPLOYMENT.md를 참고한다.

외부 출처 이미지·폰트·분석 SDK·API 요청 없음. 추가 폰트는 앱과 함께 배포한다. 이미지와 문구는 사용 중인 브라우저에만 저장된다. 같은 주소의 브라우저 데이터를 지우거나 시크릿 세션을 종료하면 사라질 수 있으므로 JSON 백업을 권장한다. 다른 탭 동시 편집은 마지막 저장을 기준으로 한다. 기기 기본 글꼴이나 이모지 대체 글꼴은 OS별로 외형이 달라질 수 있다. 같은 화면에서의 미리보기와 파일은 동일한 렌더러를 사용한다.

사용자가 제공하는 이미지의 사용 권한은 사용자에게 있다. 기본 도형 배경은 이 프로젝트에서 직접 작성한 Canvas 코드로 생성하며 외부 사진을 포함하지 않는다. 완성 이미지 3개의 제작 근거는 `docs/ASSETS.md`에 기록한다.

저장 형식·이전·용량 정책은 `docs/STORAGE.md` 참고. 12MB/24MP 입력 제한은 과제의 지정값이나 모든 기기의 성능 보증이 아니다. 정규화 사진 데이터 총량은 64MiB, 백업 입력은 80MiB로 제한한다. 브라우저 자체 용량이 먼저 부족할 수도 있다.
