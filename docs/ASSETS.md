# 이미지 제작·권한·메타데이터 기록

작성: 2026-09-21. 자동 제작과 AI 검사를 기록한다. 사용자의 제작 검토나 판단을 대신 기록하지 않는다.

외부 사진, 스톡 에셋, 실존 인물, 연락처를 사용하지 않았다. 자체 생성물이므로 원본 외부 URL·제3자 라이선스는 해당 없음. 사용자는 제출 전에 이 제작 근거와 완성본을 직접 확인해야 한다.

세 PNG를 실제로 열어 글자·그림이 보임을 확인했다. 파일 청크 검사 결과 세 파일 모두 IHDR·IDAT·IEND만 존재. eXIf·tEXt·iTXt·zTXt 0개, 위치 정보 메타데이터 0건. 기본 배경은 실행 중 Canvas에서 생성되어 원본 사진 메타데이터가 없다. 사용자 업로드도 Canvas 재인코딩 후 보관한다.

검사용 세로·가로·투명 이미지 역시 tests/browser.js의 사각형과 검사 문구로 자체 합성했다. 사용자의 개인 사진은 사용하지 않았다.
