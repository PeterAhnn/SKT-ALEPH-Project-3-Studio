# T03 · 짤·카드 스튜디오 상세 기준

출처: 사용자가 2026-09-21 대화에 제공한 개요 및 카드 1~5. 계획시간 4~5시간. 아래는 작업을 위한 요구사항 정리이며 사용자 실제 검사 기록이 아니다.

목적: 다양한 이미지와 문구를 안전하게 다루고 미리보기·내려받기·사용자 템플릿을 실제 데이터로 일치시킨다.

제출에는 결과물 주소, 소스 주소, 짧은 확인 4줄, AI와 본인 판단 3줄만 남긴다. 추가 검사 증거는 별도로 보관한다.

## 카드 1 — 편집과 미리보기

사용 권한을 확인하고 메타데이터를 제거한 합성 이미지를 준비한다. PNG·JPEG·지원하지 않는 파일을 불러온다. 이미지가 안 보이면 읽기 완료→미리보기 크기→다시 그리기 순으로 점검한다.

- C01: 모든 제출 URL을 로그인·초대·인증·비밀번호·OAuth·CAPTCHA 없이 새 시크릿 창에서 연다.
- C03: 이미지/문구 도구가 첫 화면에 보인다.
- C04/C05: PNG/JPEG 불러오기.
- C06/C07/C08: 문구 위치/크기/색 즉시 반영.
- C09/C10: 지원하지 않는 파일 거부 시 기존 작업 유지 및 이유 표시.

## 카드 2 — 화면과 파일의 일치

가장자리와 줄바꿈을 확인할 문구를 배치하고 미리보기와 파일을 나란히 비교한다. 다르면 가로·세로 크기→좌표 기준→글꼴 준비 순으로 확인한다.

- C11: 1:1의 이미지 잘림·문구 위치·줄바꿈 일치.
- C12: 4:5 일치.
- C13: 9:16 일치. 16:9가 아님.

## 카드 3 — 극단 입력 12건

예상값을 먼저 정하고 검사한 뒤 대표 결함을 고친다. 긴 문구는 폭→줄바꿈/대체 글꼴→영역 높이 순으로 확인한다.

- C14: 긴 한글·영문 혼합·줄바꿈·이모지·빈 문구·세로·가로·투명 이미지를 포함한 12건 검사 기록.
- C15: 그중 최소 한 건의 동일 입력에 실제 수정 전 FAIL→수정 후 PASS.
- C16: 잘못된 극단 입력 뒤 기존 편집 내용 보존.

## 카드 4 — 실제 템플릿 관리

세 개를 만들고 하나를 수정, 하나를 삭제한 뒤 새로고침한다. 배열 위치 대신 안정된 ID로 대상을 관리한다.

- C17: 템플릿 3개 이상 생성.
- C18/C19/C20: 불러오기/수정/삭제.
- C21: 새로고침 뒤 변경 유지.

## 카드 5 — 옮겨 쓰기와 완성본

정상·손상·필수 누락 JSON을 시험한다. 전체 검증 후 저장하고 오류 시 원본을 바꾸지 않는다. 완성 이미지 3개를 열고 권한·위치 정보·비밀값을 확인한다.

- C22: 정상 JSON 템플릿 복원.
- C23/C24: 문법 손상/필수 항목 누락 JSON 저장 전 거부, 기존 템플릿 유지.
- C25/C26: 문구 또는 비율이 다른 완성 이미지 3개 및 각각 정상 열기.
- C27: 각 이미지가 본인 제작이면 본인 제작 기록, 아니라면 출처 URL과 허가 근거 기록.
- C28: 공개 이미지 위치 정보 메타데이터 0건.
- C29/C30: 공개 화면·제출물 개인정보 0건, 공개 화면·배포 파일·제출물 비밀값 원문 0건.
- C31: 확인 방법 4항목 구분.
- C32: AI에게 맡긴 일/학생이 직접 판단한 일/AI 제안을 따르지 않은 일(없으면 이유) 구분.

제공된 상세 기준에는 C02가 없으며 임의로 추가하지 않는다. 공통 제출 항목명과 전체 커밋 소스 URL 형식은 상위 폴더 가이드와 템플릿을 따른다.
