## 재현·통과 확인 4가지

```text
어디로 가나요: https://skt-aleph-project-3-studio.vercel.app의 편집기로 갑니다.
무엇을 하나요(3단계 이내): 1) PNG/JPEG와 문구를 넣고 ‘글꼴·배치 상세 설정’에서 위치·크기·색을 바꿉니다. 2) 1:1·4:5·9:16을 골라 PNG를 내려받습니다. 3) 템플릿을 저장하고 새로고침 뒤 불러옵니다.
무엇이 보이면 통과: 미리보기와 파일의 사진 잘림·문구 위치·줄바꿈이 같고, 저장한 템플릿이 새로고침 뒤에도 보입니다.
안 될 때: 잘못된 이미지·백업 파일은 이유가 표시되고 기존 작업이 유지됩니다. 정상 PNG/JPEG 또는 이 편집기의 정상 백업으로 다시 시도합니다.
```

## AI와 내 판단 3줄

```text
AI에게 맡긴 일: 편집기·테마·무료 폰트 구현, 템플릿 저장·백업 복원, 극단 입력 검사와 결함 수정, Vercel 배포 및 검증 기록 정리.
내가 판단한 일: 시스템 기본 테마와 수동 전환, 무료 폰트 추가를 선택하고, AI 검토 결과를 보고 백업 흐름과 저장·복원·모바일 문제를 수정하도록 요청했다. 모든 검사를 직접 수행하고 최종 완성 이미지 3개를 확인했다.
AI 말을 안 들은 일: AI가 선택한 Sites 배포를 그대로 사용하지 않고 매뉴얼에 맞춰 Vercel 배포로 변경하도록 요청했다.
```
