### 미리보기·파일 비교 방법


가장자리 배치와 줄바꿈을 포함한 문구를 세 화면비에 적용한 후 다운로드 PNG를 다시 열어 Canvas RGBA 전체를 비교했습니다. 파일 크기는 각각 1080×1080, 1080×1350, 1080×1920입니다. JPEG는 손실 압축 형식이므로 픽셀 완전 동일이라고 주장하지 않습니다.


### 자료 보존 확인


사진 포함 템플릿 3개를 만들고 수정·삭제·재접속을 검사했습니다. 잘못된 이미지·JSON과 저장 공간 오류에서는 이전 저장 자료가 유지됩니다. 손상 원본은 정상 백업과 구분해 내려받고, 정상 백업 복원 후 저장을 재개합니다.

### E04: 같은 입력으로 FAIL → PASS


제출 준비 중 E04 검사 파일의 정확한 144 UTF-16자 입력을 그대로 추출해 비교했습니다. 기대값은 원문 유지, 측정 폭 준수, 사용자에게 보이는 문자 묶음(grapheme) 경계에서만 줄바꿈입니다.

| 비교 구현 | 실제 결과 |
|---|---|
| 이전 Array.from 알고리즘 재구성 | FAIL: 문자 묶음 내부 줄바꿈 8곳 |
| 현재 Intl.Segmenter 구현 | PASS: 내부 줄바꿈 0곳, 원문·폭 조건 충족 |

2026-09-21 제출 준비 중 실행한 재현 검사입니다. 보관된 과거 실패 출력과 재구성의 일치도 확인했으나, 과거에 E04 전체 입력을 실행했던 기록으로 소급하지 않습니다. 원본 과거 소스를 그대로 실행했다고 주장하지 않습니다.

### 정상·잘못된 백업


정상 파일은 내용을 먼저 보여주고 적용 버튼을 눌러야 복원합니다. 문법 손상·필수 항목 누락 파일은 저장 전에 거부하며 목록과 미리보기를 유지합니다. 저장 중 실패하면 사진과 문서를 함께 롤백합니다. 이전 v1 백업도 읽을 수 있습니다.


### 공개 안전과 구현 한계


사진과 문구는 브라우저 내부에서 처리하고 저장합니다. 외부 사진 URL·SVG는 복원하지 않습니다. 추가 폰트 7종은 공식 배포본의 OFL 1.1 고지를 함께 제공합니다. 공개용 자료에 계정 인증 정보나 개인 사진을 포함하지 않았습니다.

입력 12MiB·24MP, 템플릿 최대 12개, 정규화 사진 총량 64MiB는 구현 정책이며 과제 지정값이 아닙니다. 단색 24MP 입력의 데스크톱 측정은 약 391ms였지만 모바일 전체 성능을 보증하지 않습니다. 브라우저 자료 삭제에 대비한 파일 백업은 여전히 필요합니다.
